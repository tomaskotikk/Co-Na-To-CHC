# Vlastní zvuky (volitelné)

Když sem dáš soubor s jedním z těchto jmen (mp3 / ogg / wav / m4a), přehraje se místo vestavěného zvuku:

| Soubor | Kdy zazní |
|---|---|
| `correct.mp3` | trefa — otočení karty s body |
| `wrong.mp3` | BZZZ — chybná odpověď |
| `intro.mp3` | ohlášení otázky (žlutý stěrač) |
| `softFlip.mp3` | otočení karty při „Odkrýt zbytek“ |
| `suspense.mp3` | napětí během prodlevy (hraje ve smyčce, utne se) |
| `drumroll.mp3` | vířivý buben (intro show, finále) |
| `crash.mp3` | činel po bubnu |
| `fanfare.mp3` | fanfára + potlesk (intro show, vítěz) |
| `buzz.mp3` | tým zmáčkl bzučák na telefonu |
| `pop.mp3` | tým se připojil |
| `tick.mp3` | krok zpět |
| `applause.mp3` | potlesk po trefě a u vítěze (vestavěný není — hraje jen když ho sem dáš) |

Zvuky musí být tvoje nebo s licencí, která povoluje použití (např. Pixabay, Mixkit, freesound CC0).
Po přidání souborů je pushni na GitHub — Render je nasadí s aplikací.
